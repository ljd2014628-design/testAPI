# 接口测试工具 · 使用说明

## 一、启动

双击 **接口测试工具.exe**，直接弹出程序窗口，和微信一样。不装 Python、不开浏览器、不联网装东西。

- 适用 Windows 10 / 11 64 位。
- 首次启动要解压内置运行环境，约 5~15 秒才出窗口，属正常现象，之后会快很多。
- 所有配置、用例、执行结果存在 exe 同级的 **`data`** 文件夹（`state.json`），关掉再开自动恢复。
- exe 建议放桌面或 D 盘等有写权限的目录。放在只读目录时会自动改存到 `C:\Users\你的用户名\ApiTestTool\data`。
- 部分杀毒软件会对这类打包程序误报，加信任放行即可。双击没反应基本就是被拦了。

## 二、界面一览

```
┌ 顶部：程序名 / 当前文件       生成Excel模板  导入Excel  导出结果  重置工具 ┐
├ 公共配置：BaseURL、编码、超时、校验SSL  |  公共请求头/信息头（每行一个）  │
├ 执行区：▶全部执行   ▶执行选中的接口/场景   清空执行结果                   │
└ 三个标签页：接口用例 | 组合场景（多接口） | 执行日志                       ┘
```

## 三、五分钟上手

1. 点 **生成Excel模板**，存到本地 → 用 Excel 打开填接口（里面有 3 条黄色示例行，可直接改）。
2. 点 **导入Excel** 选中刚填好的文件（已有数据时会问你覆盖还是追加）。
3. 在 **公共配置** 里填 BaseURL、公共请求头、编码（默认 utf-8）→ 点 **保存配置**。
4. 点 **▶ 全部执行**；或者在列表最左边「选择」列点一下打勾，再点 **▶ 执行选中的接口 / 场景**。
5. 点 **导出结果**，得到含导入内容 + 执行结果的 Excel。

**列表里快捷改名**：双击「接口名称」或「接口用例」这两列，单元格会直接变成输入框——

- **回车** 保存，**Esc** 取消，点到别处也会自动保存；
- 在「接口名称」格按 **Tab** 可直接跳到同一行的「接口用例」继续改；
- 右键菜单里也有「修改接口名称」「修改接口用例」两项。
- 「组合场景」页双击场景名称同样可以就地改。

双击**其他列**则打开完整编辑窗口；**右键某一行**还有复制、执行、测试提取、查看结果等快捷操作。

## 三点五、cURL 导入与复制用例

**cURL 导入**：「接口用例」页左上角 **cURL 导入** → 把 cURL 粘进去 → **解析** → **导入为新接口**。

- 支持浏览器 F12 → Network → 右键请求 →「复制为 cURL (bash)」或「复制为 cURL (cmd)」，也支持 Postman / Apifox 导出的 cURL。
- 能识别：请求方法、URL、所有 `-H` 请求头、`--data / --data-raw / --json` 等 Body、`-u` 账号密码、`-b` Cookie、`-G` 查询参数。
- 一次可以粘贴多条，会各自生成一个新接口。
- **导入只会新增接口，不会覆盖已有的**。只导入一条时会直接弹出编辑窗口，接口名称、接口用例说明等都可以当场改。
- 两个默认勾选的选项：URL 和公共 BaseURL 前缀一致时自动转成相对路径；去掉浏览器自动附带的无关头（`sec-ch-*`、`sec-fetch-*`、`priority` 等）。
  `Accept-Encoding`、`Content-Length`、`Host` 这三个始终会去掉（由工具自动生成，保留反而可能导致响应乱码）。
- 暂不支持 `-F` 文件上传类请求，遇到会给出提示。
- cURL 导入的接口和手工录入的完全一样，**导出 Excel、再导入都能原样还原**。

**复制用例**：选中一行点 **复制**（或右键 → 复制为新用例，或在编辑窗口点「保存并复制为新用例」）。

- 新用例的「接口用例」自动加后缀：`正常查询` → `正常查询_copy1` → `正常查询_copy2` ……，复制副本也会继续递增，不会重名。
- 用例ID 自动分配新的，执行结果不会被复制，新副本排在原用例及其已有副本后面。

**请求头多的时候**：编辑窗口里请求头区域右上角会显示「共 N 个请求头」，区域支持上下、左右滚动；
请求头、Body、提取变量三块之间的分隔线可以拖动，把请求头区域拉大看。
查看结果里的请求头也改成了一行一个，方便滚动浏览。

## 三点六、请求参数与字段备注

打开接口编辑窗口，中间区域有三个页签：**请求参数（URL）**、**请求 Body**、**Body 字段备注**。

**这三个页签是互斥的**：一个接口要么用 URL 参数，要么用 Body，不会同时用。

- 参数表里有内容 → 「请求 Body」变灰不可填写；
- Body 里有内容 → 参数表锁定不可编辑；
- 想换一种：被锁的那页上有一个按钮（「清空 Body，改用 URL 参数」/「清空 URL 参数，改用 Body」），点一下确认即可切换；
- **「Body 字段备注」只有在 Body 有内容时才可用**，Body 为空时该页签是灰的；
- 老数据里万一两者都有内容，会在两页都标红提示，点任一按钮二选一即可。

**请求参数（URL）** —— GET 请求主要用这里：

- 打开接口时，URL 里的 `?a=1&b=2` 会**自动拆到这张表，一行一个参数**，URL 输入框只留干净的地址。
- 三列：**参数名 / 参数值 / 备注**。双击单元格修改，回车保存，Tab 跳到下一格。
- 最左边的「启用」勾掉，这个参数本次就不发送，但行还留着，不用删了再加回来。
- 「粘贴 URL / 参数串解析」可以把一整条 URL 或 `a=1&b=2` 粘进来，自动拆成多行追加。
- 上方蓝色的「实际请求」会实时显示拼好的完整 URL，所见即所得。
- 参数值里同样能用 `${变量名}` 引用上一个接口提取的值。
- POST 等其它方法也能用这张表加查询参数，和 Body 不冲突。

**Body 字段备注** —— POST 等带 Body 的请求用这里：

- 会把 Body 的 JSON 拆成一行一个字段（嵌套字段显示成 `lines[0].unitPrice` 这种路径）。
- 双击「值」可以直接改并写回 Body（数字、true、null 会保持原类型）；双击「备注」写注释。
- 切到这个页签会自动重新解析 Body；改完 Body 再切回来即可刷新。

**备注只存在本地，发请求时绝不会带上**，URL、Body、请求头里都不会出现。导出 Excel 时存在
「URL参数」和「字段备注」两列里，重新导入照样还原。

## 三点七、断言（判断接口是否符合预期）

接口编辑窗口底部有两个页签：**提取变量** 和 **断言（预期结果）**。断言表六列：
启用 / 目标 / 比较方式 / 期望值 / 级别 / 备注。

- **目标**：`$.data.total` 这类 JSON 路径，或 `状态码`、`耗时ms`、`响应文本`、`响应头.Content-Type`
- **比较方式**：40 多种，分六组（数值相等 / 文本 / 存在空值 / 类型结构 / 数组集合 / 与上次比较）
- **级别**：「必须通过」不满足就判失败；「仅警告」只提醒，不影响结论（适合耗时这类指标）
- **从响应选字段**：点开响应树选字段自动填路径
- **常用断言**：按场景一键加一组（健康检查 / 列表分页 / 领券库存 / 结构校验 / 反向用例）
- **▶ 试跑断言**：立刻跑一遍看结论，不写入执行历史、不影响「较上次」基线

**领券这类每次都变的数据**，用 `$.data.remain [较上次减少] 1`：第一次记基线，
之后 10→9、9→8 都通过，变成 9→7 才报错，期望值一次都不用改。
也可以用 `${变量}-1` 这种算式，或只校验规律（正则、类型是、长度大于）。

公共配置里可勾选 **「组合场景里断言失败就停止后续步骤」**。

导出的 Sheet1 末尾两列：**预期结果内容**（断言配置，可直接在 Excel 里改）、
**是否符合预期**（最近一次结论 + 每条明细）；Sheet2 也有「是否符合预期」列。

> 完整的比较方式速查、写法示例和实践建议，见单独的 **《断言使用手册.md》**。

## 四、Excel 模板结构

| Sheet | 作用 |
|---|---|
| **接口用例** | 接口清单 + 最近 5 次返回结果（返回结果1 永远是最新一次） |
| **组合场景结果** | 工具自动写入：多接口组合场景的最新一次结果，按行记录 |
| **场景配置** | 组合场景的步骤编排（也可以在界面上建，导出会写回这里） |
| **公共配置** | BaseURL / 编码 / 超时 / 校验SSL / 公共请求头 |

### 接口用例各列

| 列 | 说明 |
|---|---|
| 用例ID | 唯一标识，组合场景靠它引用，如 `CASE_001`。留空会自动补 |
| 接口名称 / 接口用例 | 名称与用例说明 |
| 接口URL | 相对路径自动拼 BaseURL；也可直接写 `http://` 完整地址；支持 `${变量}` |
| 请求方法 | GET / POST / PUT / DELETE / PATCH |
| 接口请求头 | **只填该接口特殊的头**。两种写法：`{"token":"abc"}` 或每行 `token: abc` |
| 请求Body | POST/PUT 填 JSON；GET 留空 |
| URL参数 | 每行 `key=value`，`#` 后面写备注，行首加 `#` 表示这行不发送。例：`brandCode=K001  # 品牌编码` |
| 字段备注 | 每行 `字段路径 = 备注`，例：`lines[0].unitPrice = 单价，单位分`。只给自己看，不会发送 |
| 预期结果内容 | 断言配置，每行 `目标 [比较方式] 期望值  # 备注`，例：`$.data.remain [较上次减少] 1` |
| 是否符合预期 | 执行后自动回填，无需手工填写 |
| 是否执行 | `Y` 参与「全部执行」，`N` 跳过（界面上仍可单独勾选执行） |
| 提取变量 | 每行一个 `变量名=$.json路径`，把响应值存成变量供后续接口用 |
| 返回结果1~5 | 工具执行后自动回填，**无需手填**，1 = 最新一次 |

## 五、请求头优先级

```
接口级请求头（接口编辑窗口 / Excel 第6列）   ← 优先读这里
        ↓ 同名时覆盖公共
公共请求头（主界面公共配置区）               ← 兜底
```

同名判断不区分大小写（`Content-Type` 会覆盖 `content-type`）。
主界面的公共请求头每行一个 `名称: 值`，**行首加 `#` 表示停用这一行**。请求头值支持中文。

## 六、多接口组合测试

**建场景的两种方式**

- 在「接口用例」页把要组合的接口打上勾 → 点 **用勾选的接口组合成场景**（按列表顺序生成步骤）；
- 或到「组合场景」页点 **+ 新建组合场景**，再逐个 **+ 添加步骤**。

步骤可以上移下移调顺序，双击某步骤可改它的提取变量。

**参数传递**

1. 前一个步骤的「提取变量」里写：`couponId=$.data.lines[0].couponInstanceId`
2. 后一个接口的 URL / Body / 请求头里用 `${couponId}` 引用，例如
   `/coupon/query/${couponId}?brandCode=K001`

写法要点：

- **一定要有等号左边的变量名**。只写 `$.data.list[*].id` 是不生效的，要写成 `ids=$.data.list[*].id`。
- 路径 `$.` 开头，点号取字段，`[0]` 取数组第几个，`[*]` 取整列，例如：
  - `$.data.total` → 单个值
  - `$.data.list[0].id` → 数组第一条的 id
  - `$.data.list[*].id` → 所有条目的 id，结果是一个数组
- 步骤的提取变量留空，则沿用该接口在用例里自带的提取配置。

**测试提取 / 点值生成路径（重点）**

入口：接口编辑窗口的 **「测试提取 / 点响应值生成路径」**、主界面第二排的同名按钮、右键菜单、场景步骤窗口。打开后：

- 窗口下半部分是**树形展示的响应**，像文件夹一样层层展开。**单击任意字段**，上方立刻生成它的路径（如 `$.data.list[1].cuonc`）和建议的变量名。
  - **添加为变量**（或直接双击字段）：写入 `cuonc=$.data.list[1].cuonc`
  - **取整列 [*] 添加**：字段在数组里时，一次取出所有项，写入 `cuoncList=$.data.list[*].cuonc`
  - **复制路径**：只复制路径到剪贴板
- 每添加一条会立即校验，上半部分直接显示取到了什么。

- 上方选数据来源：**用该接口最近一次的执行结果**（快，不发请求），或 **立即发起一次请求**（取最新响应，且不会计入结果历史、不污染你的 5 次记录）。
- 中间表格逐行告诉你每条配置的结果：
  - `✓ 取到了` 并显示取到的值（数组会标出共几项）
  - `△ 取到了，但值是 null` / `空数组` —— 路径对，但数据本身是空的
  - `✗ 没取到：路径在响应里不存在` —— 路径写错了
  - `格式错误：缺少「变量名=」` —— 少写了变量名
- 下方直接显示完整响应内容，对照着改路径；双击表格某一行可查看该变量的完整取值。
- 在这个窗口里可以直接改提取配置反复测，测通后点 **应用并关闭** 写回。
- 「响应（原始文本）」页签可看原始返回内容。

**场景名称**：多接口（≥2 步）时必填，会写进导出 Excel 的 Sheet2。

## 七、执行结果与导出

- 每个接口、每个场景各自保留 **最近 5 次** 结果，超过自动挤掉最旧的。
- 选中一行点 **查看结果**，窗口上方有「第1次(最新)…第5次」页签，可看完整的请求URL、请求头、Body、提取到的变量、响应。
- **响应内容过长时默认折叠**（只显示前 2000 字并标明省略了多少字符），窗口左上角点
  **「展开全部内容」** 看全文，再点一次收起；旁边还有 **「把当前页完整内容另存为 txt」**，
  方便把大段响应拿去别处比对。
- **导出结果** 生成的 Excel：
  - Sheet1「接口用例」= 你导入的全部内容 + 返回结果1~5；
  - Sheet2「组合场景结果」= 组合场景**最新一次**结果，按行记录：场景名称、步骤、用例ID、接口名称、方法、**完整URL**、**请求Body**、响应状态、**请求结果**、耗时、执行时间。

## 八、清空结果

| 入口 | 范围 |
|---|---|
| 执行区的 **清空执行结果** | 所有接口 + 所有场景 |
| 接口用例页的 **清空该接口回参** | 只清选中的那一个接口 |
| 组合场景页的 **清空该场景结果** | 只清选中的那一个场景 |

三个入口一样：如果存在多次执行结果，会弹窗让你选 **全部 N 次** 还是 **第 X 次**；只有 1 次时直接清空。

## 九、常见问题

**执行报 Connection refused / Timeout**：BaseURL 写错，或本机连不上测试环境。

**报 SSL 错误**：把「校验SSL证书」的勾去掉。

**响应中文乱码**：把「内容编码」改成接口实际编码（默认 utf-8，老系统可能是 gbk）。

**变量没替换（URL 里还是 `${xxx}`）**：说明变量没取到。最快的排查方式是打开那个接口，
点「测试提取」，它会直接告诉你每条配置是取到了、取到 null、还是路径不存在。

**执行时窗口会不会卡住**：不会。请求跑在后台线程，执行期间界面可正常操作，状态栏显示进度，
「执行日志」页可以实时看每个请求的结果。

**想先确认工具本身没问题**：BaseURL 填 `https://httpbin.org`，新增一个 `POST /post` 的接口，
Body 随便填个 JSON，执行后能看到回显即说明一切正常。

**数据会不会丢**：实时存在 exe 旁边的 `data/state.json`，重启自动恢复。
想从零开始点右上角「重置工具」。换机器就把 exe 和 `data` 文件夹一起拷走，或只拷导出的 Excel 重新导入。

**启动失败**：`data` 文件夹里会生成 `error.log`，把里面内容发我即可定位。
